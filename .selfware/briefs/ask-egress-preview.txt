# TASK: ask-egress-preview — preview, confirm and log what `sahara ask` sends to a cloud model (GitHub #118, P1 slice: dry-run, audit, local log)

When answer_provider is openai or ollama, `sahara ask` sends the question plus retrieved snippets to the provider, and the user cannot see that payload first or later. Add a preview, an opt-in confirm step and a local metadata-only log. Out of scope, to be separate briefs and the reason #118 stays open: redaction and never-send path globs, MCP-aware controls, source classification. Do not touch the MCP server.
1. src/sahara/search/ask_engine.py: add a frozen dataclass EgressPreview (provider, model, destination host, leaves_machine, sources as (storage_prefix, relative_path, score, chunk_id), char_count, est_tokens, truncated, context text) and AskEngine.preview(question, top_k, storage_prefix). leaves_machine is True for openai, True for ollama unless the ollama_url host is loopback (localhost, 127.0.0.0/8, ::1), False for none. est_tokens is char_count // 4 and is documented as an estimate. Refactor ask() so preview() and ask() share one helper that does the local search and builds the context with _build_context; the previewed sources and text must be exactly what ask() would send. preview() must never open a network connection; add a test that patches urllib.request.urlopen to raise and still passes.
2. src/sahara/storage/state_db.py: add table egress_audit (id, requested_at, provider, model, destination, query truncated to 500 characters, sources_json holding only storage_prefix, relative_path and chunk_id per source, char_count, est_tokens, outcome in previewed|sent|declined|failed, details) created with IF NOT EXISTS like mcp_memory_audit, plus record_egress_event(...) and list_egress_events(limit). It must never store snippet or context text. Existing databases must open unchanged.
3. src/sahara/cli.py, `sahara ask`: add --dry-run (run the preview, print provider, model, destination, whether data leaves the machine, numbered sources with path and score, characters and estimated tokens, record a previewed event, never call the provider, exit 0; also valid when provider is none, where it says nothing leaves the machine and records no event), --audit (print the same preview, then ask "Send this to <destination>? [y/N]" and only call the provider on yes; a no, EOF or a non-interactive stdin counts as declined, is recorded as declined and exits 0 without a call) and --no-confirm (only with --audit: skip the prompt, still print and still record). --show-payload prints the exact context text that would be sent, and is valid only with --dry-run or --audit. --dry-run wins over --audit. Every other ask that really calls openai or ollama records one sent or failed event; provider none records nothing. Existing behaviour and output without the new flags are unchanged apart from the event write.
4. src/sahara/cli.py, new command `sahara egress-log [--limit N]` (default 20) listing recent events newest first: time, outcome, provider and model, destination, source count, estimated tokens, and the query. Say in the output header that no document text is stored.
